# Projeto de Inteligência Artificial Aplicada (PIAA)

This repository contains the practical project developed for the **Projeto de Inteligência Artificial Aplicada** course . The research focuses on analyzing regional asymmetries in educational performance in Portugal using microdata from PISA 2022.



## 🎯 Project Objective
The main objective of this project is to map, characterize, and understand the socioeconomic and institutional factors that drive inequalities in academic performance (specifically in Mathematics) across different regions and sub-regions of  Portugal.



## 📝 Project Summary
To achieve the proposed goals, the workflow was structured into the following stages:
* **Data Processing & Integration:** Cleaning, consolidating, and denormalizing the original OECD context questionnaires (students, schools, and teachers) into a single, optimized dataset.
* **Oaxaca-Blinder Decomposition:** Applying this econometric method to split the test score gaps between pairs of regions into two distinct components: explained and unexplained .
* **Segmentation via Clustering ($K$-Means):** Running a clusterin algorithm based on variable contributions to group the country's sub-regions into 3 distinct profiles , highlighting how territorial asymmetries shape the school ecosystem.
